Search official Lance `INVERTED` full-text indexes from browsers and workers: BM25-ranked match (OR/AND, fuzzy, prefix), phrase, and boolean queries through `LanceDataset.ftsIndexes()` and `searchRows()`. The reader decodes Lance's FST token sets, bit-packed posting blocks, and positions with bounded range requests, reproduces the index's English analyzer pipeline (including a Snowball stemmer and ASCII folding), skips rows deleted after indexing, and streams postings in bounded, columnar batches into a top-k heap so memory is admitted before allocation and never grows with match count. Index file directories and the per-partition query plan are reserved before they are built (`search.directoryBytes`, `search.planBytes`), range readers charge read plans and every returned container, rows deleted after indexing are filtered while ranking so one scan returns the final result without rescoring, the corpus token total is summed lazily in parallel chunks (never for absent terms), and query analysis is charged as it runs. Rankings and scores are verified against pylance 8.0.0, and deterministic network-wave tests bound dependent round trips, requests, bytes, and memory.
